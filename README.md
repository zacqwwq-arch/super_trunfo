# Super Trunfo - Nível Novato

Programa em C para cadastrar **duas cartas** do Super Trunfo (tema: Países).

## Descrição
Este projeto implementa o requisito do nível novato: ler do usuário os dados de duas cartas e exibi-los formatados.  
O programa foi escrito em linguagem C e segue as restrições do desafio (sem loops, sem if/else).

## Arquivos
- `super_trunfo.c` — código-fonte em C
- `README.md` — documentação
- `.gitignore` — ignorar binários
- `docs/1.pdf` — material do curso (opcional, copiado do envio original)
